# CodeAlpha Flashcard Quiz App

A clean, responsive flashcard quiz application created for the CodeAlpha App Development internship.

## Features
- Question and answer flashcards
- Show Answer / Show Question
- Previous and Next navigation
- Add flashcards
- Edit flashcards
- Delete flashcards
- Persistent storage using browser localStorage
- Responsive UI for desktop and mobile

## How to Run
1. Download or clone the repository.
2. Open `index.html` in a modern web browser.
3. No server or package installation is required.

## Project Structure
- `index.html` — application layout
- `style.css` — styling and responsive design
- `script.js` — flashcard logic and localStorage

## CodeAlpha Requirement Mapping
- Question on front and answer on back: implemented.
- Next and Previous navigation: implemented.
- Add, edit and delete: implemented.
- Simple, clean UI: implemented.
