# CodeAlpha Random Quote Generator

A clean and minimal random quote generator created for the CodeAlpha App Development internship.

## Features
- Displays a quote when the app opens
- New Quote button
- Random quote selection
- Shows quote text and author clearly
- Avoids immediately repeating the previous quote
- Responsive, minimal UI

## How to Run
1. Download or clone the repository.
2. Open `index.html` in a modern web browser.
3. No server or package installation is required.

## Project Structure
- `index.html` — application layout
- `style.css` — styling
- `script.js` — quote data and randomization logic

## CodeAlpha Requirement Mapping
- Random quote on app open: implemented.
- New Quote button: implemented.
- Quote text and author: implemented.
- Clean/minimal UI: implemented.
